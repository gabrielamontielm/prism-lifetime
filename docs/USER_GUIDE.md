# LifePrism User Guide

Welcome to LifePrism! This guide will help you master the art of curated memory tracking.

## 🧭 Navigation & Layouts

LifePrism offers multiple ways to view your life's milestones. Toggle between them in the **Top Navigation Bar**.

### 1. Standard Timeline
- **Best for**: Casual browsing.
- **Features**: Large visual cards, staggered animations, and full descriptions.

### 2. Compact View
- **Best for**: Rapid scanning for specific dates.
- **Features**: Text-heavy, minimal images, high information density.

### 3. Map View
- **Best for**: Seeing your geographical footprint.
- **Features**: Interactive Google Maps with milestone markers. Click a pin to see a preview card.

### 4. Story Mode
- **Best for**: Immersive recollection.
- **Features**: Full-screen, auto-advancing slides with blurred background focus. Perfect for sharing or "Stories" style viewing.

### 5. Bento Grid
- **Best for**: High-level visual aesthetic.
- **Features**: Irregular grid patterns that highlight standout memories with dynamic sizing.

## 💎 Creating a Milestone

1. Click the **"New Milestone"** button (or `+` icon).
2. **Phase 1: The Basics**: Enter a Title and pick a Date.
3. **Phase 2: Location**: Search for a location using Google Places integration. Use the predicted results for precision.
4. **Phase 3: Visuals**: Upload a primary photo. LifePrism will automatically resize and optimize the image for performance before upload.
5. **Phase 4: Collaboration**: Invite others to your memory. (Search for users by email).

## 🔍 Filtering & Searching

- **Search Bar**: Type any text to search titles, notes, or locations.
- **Tag Cloud**: Click a tag like `#Travel` or `#Family` to filter your timeline instantly.
- **"All Lifelines"**: Resets filters to show all events.

## 🤝 Collaborative Memories

When you add a collaborator to a milestone:
- They can view the memory in their own timeline.
- They see themselves listed as participants.
- Milestones remain secure—only explicitly added collaborators have access.

## 📱 Mobile Tips
- **Swipe**: In Story mode, you can tap the left/right sides to navigate manually.
- **Map**: Use pinch-to-zoom to explore clusters of memories in one city.
- **Bento**: On mobile, the Bento grid automatically collapses into a single column for readability.
